### RSA: the issue's held-dependent exception

`cargo update -p rsa@0.10.0-rc.18 --precise 0.10.0 --offline --dry-run` exits 101:

```text
package `llrt_crypto` depends on `rsa` with feature `sha2` but `rsa` does not have that feature.
note: a required dependency with that name exists, but only optional dependencies can be used as features.
```

`llrt_crypto` 0.9.0-beta at `7b95c82a9b15e7ddfb2778eca4b5a63111e74f51` requests `rsa ^0.10.0-rc.18` with the optional `sha2` feature. RSA 0.10.0 makes sha2 mandatory and removes that implicit feature. The chain is gpui-shell → quickjs-jit-stdlib → llrt_crypto. This is not a version-comparison failure and changing the upstream pin is outside the lock-only task. RSA remains affected by RUSTSEC-2023-0071; #2359 owns the dependent fix. No RSA ignore is added.
