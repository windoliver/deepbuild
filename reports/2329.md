| Benchmark child counts before/after | Unchanged `benchmarks/hub.mjs compact`, counted with `scripts/count-children.c` | **2,044 → 4 `ps`**, 3,115 → 1,074 total children |

A same-process compaction cannot change its launch arguments/start. A changed candidate parent set can change its link, so that invalidates the parent lookup. A failed lookup is not cached. The retained candidate key is a fixed-size digest, and weak keys bound the cache lifetime to the sessions. Resumes read again. Plugin settings/registry/directory stat keys and expiry remain unchanged; only process facts are reused. The new-set reader captures the verified process start before asynchronous work and still reads freshly on resume.

This belongs in the hub's existing session-identity/adapter path: an extension cannot prevent the core's own process inspections without changing that path.
