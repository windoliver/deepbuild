## Changes since the first numerical pass

- Carry the first implementation and byte-identical frozen acceptance drafts onto current main. The original AO shader/host and #418 tests are identical between the drafting base and this base.
- Surface-aware half-resolution lookup: bilinear AO taps agree with the shaded receiver's tangent plane using the real prepass depth. Full resolution keeps its direct lookup. If a subpixel/curved receiver supplies no matching tap, preserve nearest measured AO rather than inventing visibility 1. Uses geometric receiver normals, not a normal map, for surface membership.
- Keep the GPU's existing sampled-texture limit: a first attempt bound depth and normals and failed at 17 textures versus limit 16. The correction uses depth plus the receiver's normal only; no device-limit increase or feature fallback was added.
- Guard each planted shader substitution with `find(...).expect(...)`, so a stale substitution cannot silently leave the shipped estimator. `ao_points_at_radius` (the redraft's name) selects exactly the same code as `ao_full_radius`.
- Move the GPU-layer adapter/pass declarations and proof switches into `src/module.rs` and `src/planted.rs`, re-exported at the unchanged public crate root; move AO shading and the ambient functions that consume it into `ao_shade.wgsl` and `ambient.wgsl`. No test was moved. After retaining upstream inset work, `lib.rs` is 9,168 lines and `scene3d.wgsl` 3,159; both ceilings are below the new merge base's 9,169 / 3,163. Frame data types also move intact into the existing adapter module to keep the ceiling. No ceiling is raised. The moves keep the touched over-ceiling files from increasing the existing delivery gap.
- Separate aggregate declared AO job cost from the three independently named timing scopes in comments. The qualified merged-source run now supplies the design Cost line; the declaration is not itself a measurement.

These remain changes to the existing render module; an extension cannot replace its internal AO prepass binding/shader. No kernel, dependency, default radius/strength, history or ray-query feature changes.
