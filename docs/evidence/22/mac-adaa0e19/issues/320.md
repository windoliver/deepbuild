An unblock ask as a task with its steps and its check, and a block owned by someone else turned into a drafted request for them.

**Epic:** #2 · **Part of:** #22 · **Design:** [An ask, and your answer getting back](https://github.com/windoliver/deepbuild/blob/main/docs/technical-design.md#an-ask-and-your-answer-getting-back) · [Checks for work beyond code](https://github.com/windoliver/deepbuild/blob/main/docs/technical-design.md#checks-for-work-beyond-code)

### Scope
- An unblock is a task only you can do: the steps, where, why, what it unblocks and the check that proves it; "I did it" re-runs that check (the done gate, #32), and past its deadline the definition's fallback applies or the claim stays BLOCKED
- A BLOCKED item owned by someone else gets a drafted request for that owner, not an inbox item for you

### Acceptance criteria
- [ ] A block owned by someone else never reaches your inbox; its drafted request does
- [ ] A task with a cost you pay shows the price
- [ ] A task without its steps, where to take them, what it unblocks and the check that proves it fails its schema
- [ ] A drafted request for someone else is re-checked against its source before it's shown, and one whose item has changed says so

### Proof
A task schema refusal, a block owned by someone else kept out of your inbox, and a drafted request re-checked against its source, each shown failing first.
