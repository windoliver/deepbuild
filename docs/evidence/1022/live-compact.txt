#1022: one live /compact in the Codex CLI (Codex 0.144.0, the version installed on this Mac; 0.160.0 is not installed here).

How: live-compact.py drives the real Codex TUI in a pty against spikes/1330/fake-openai.mjs (a local stand-in model, no spend),
with DeepBuild's own hooks written by `deep setup` and a real `deep hub run`, all in a scratch HOME under /tmp. It types
"say hi", waits for the turn, types /compact, waits for the compaction, quits, lets the hub drain, and prints the session's record.

Codex's own hooks for that run (logged raw, no DeepBuild): SessionStart, UserPromptSubmit "say hi", Stop, then PreCompact
(trigger manual) and PostCompact under a new turn_id. Codex fired no UserPromptSubmit for /compact.
