Why each test fails at the base, read from the base's code:

- scripts/contract-diff.mjs reads `since`, `stability`, `tracking`, `deprecated_since`, `replaced_by` and
  `stops_serving` of an entry (entriesOf) and nothing else, so `preview_since` and `decide_by` are never read:
  historyProblems has no rule for either, for the candidate being an entry's `decide_by`, or for a `decide_by` that
  moved. contracts/extensions.json is read by nothing.
- breaksAgainst skips an entry when it was a preview in the earlier release or is one now ("A preview entry is
  outside the break diff, whatever it was or became"), so a promoted entry is never diffed against the release that
  recorded it as a preview.
- diffAll asks, for each break, whether a break file of the pair quotes its lines. No code asks whether a quoted line
  is still in the diff, so a break file left behind by a restored method changes nothing.
- notes prints the accepted breaks only.
- packages/hub/src/index.ts exports no `extendPreview`.
- crates/deep-show/src/kinds.rs gives a preview entry `stability` and `tracking` only.
- crates/deep-show/Cargo.toml has no `test-preview-removed` or `test-preview-removed-bare` feature.
