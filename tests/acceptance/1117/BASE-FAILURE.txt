## A planted program, and the planted wrong programs

No implementation exists yet. To check that the tests can pass and that each named wrong program fails them, a
throwaway planted bays.mjs (written for this check only, kept out of the repository; it reads the tree's files straight
from the worktree by listFiles, not from a git archive and bundle, compares bytes, seals target/ and node_modules/ by path, size, mtime_ns and inode, and claims
through throttle.mjs's acquire('bay-pair')) was put at scripts/bays.mjs in a scratch copy of this checkout
(node_modules linked). On the Spark (20 cores, Linux arm64, cargo 1.99.1, node 24.22.0):

  ℹ tests 10, pass 10, fail 0, in 76 s (the two proofs.test.mjs tests take about 38 s each, all of it
  tests/proof.test.mjs and tests/acceptance/569/before.test.mjs; every other test takes 1-2 s).

Then one rule at a time was broken in that planted program (PLANTED_TWIN=<name>), and the suite run again:

- blob-id-compare (decides which files to write by the blob ID it last wrote, not by the bytes on disk):
  ✖ #1117.b2c7cfc4 a run after an aborted run rebuilds every file the abort left different, …
  ✖ #1117.af1d4c7e a planted mutant or a rewritten kit-ledger.json from a previous run never survives …
    AssertionError: the bay does not hold exactly the tree's files and bytes (outside .git, target and node_modules)
  every other test passed.
- relocated-target (each run gets a new folder and the warm target is moved in, and back after):
  ✖ #1117.e77894d3 … AssertionError: the second run of the same tree used another bay path, …
  ✖ #1117.029c15e6 … AssertionError: the bay build did not write <sandbox-home>/deepbuild-bays/1/run-…/target/debug/greet
  (and, by its bookkeeping, #1117.af1d4c7e, both #1117.4ebbfb21 and #1117.f25af808); #1117.b2c7cfc4 and
  #1117.a9ce2b57 passed.
- trusted-seal (a seal that exists is taken as intact, its stat listing never compared):

  every other test passed.

  ✖ #1117.af1d4c7e … AssertionError: crates/word/src/lib.rs was put back with an mtime from before this run (2001-09-09T01:…)
