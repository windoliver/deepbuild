 Test Files  4 failed (4)
      Tests  16 failed (16)

Every test fails. None passes. On Linux the base's native helper (helper-linux.c) has no `pty` mode, so no hosted
terminal starts: every scenario but AC7's throws at its first `deep.terminal.open`, before its criterion can be
reached (the scenario can't run, so it fails; it never passes). AC7's fails first on the missing TERMINAL_PROTOCOL
export. The type check (`npx tsc -p tests/acceptance/989/tsconfig.json`) fails too, on the missing surface only:
TerminalTab, ExtensionHost.tab and .resize, the `terminalProtocol` option and the nine new Plant values. On macOS the
base's helper does run a hosted terminal; there each scenario would get past its open and fail at `ExtensionHost.tab`
or `.resize` (not functions), at `deep.terminal.close` (not in the API), or, for AC5, with the program reading
"echo planted" through the base's FIFO; that run was not made here.
