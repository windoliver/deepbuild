  changed to restart the hub itself (README: Why a restart of its own).
- Run 4: `deep hub stop` returns only when the hub closes the stop's own connection, which a stopped hub does at
  process exit. A linger placed before that close is invisible to the start. The final twin and control close that
  connection first, then linger 3 s with the lock released (the gap the issue describes, made certain).
