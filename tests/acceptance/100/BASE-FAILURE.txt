# #100 acceptance tests: the runs on the base, on a stand-in and on each twin

2026-11-25, Node v24.22.2, on a shared machine at a load of about 66. Each `$` line is one real run of that command,
with the spec reporter and scripts/proof-reporter.mjs beside it. Kept of each run: every test's result line, and of
each failure its error line, the lines its diff adds and its frame in the suite. Dropped: the runner's count lines, the
rest of the diff and the runner's own frames. Each `judged` line reads the same run's proof report by the rule of
atAssertion in scripts/proof-runs.mjs: an ERR_ASSERTION whose innermost frame is under the test paths. `exit` is the
runner's exit code. <checkout> is the checkout and <scratch> a scratch folder outside it.

On the base the first test fails at its assertion, for the issue's reason: neither Decided table has the row. The
second passes there, since the base's docs hold that half of the criterion; the twin solver-waits-on-review is what it
fails on. The live test doesn't read the checkout: it read the 2,160 issues of that day and found none waiting.
