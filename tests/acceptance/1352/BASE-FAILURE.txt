## The planted fix and its mutants (a scratch clone, never this checkout)

A `git clone` of this worktree into the session scratchpad at 6aa228ce, with the tests copied in. The planted design,
written for the harness only: the two old sentences reworded (Socket roles' to "a web client reaches only its person's
own hub", Injected answers' to "A web page reaches no hub but through the web client below."); a threats row "A browser
reaching the hub" naming the web client, the person's own hub, the authenticated connection and a passkey; a clause
added to Privacy's "Nothing leaves the machine" line with the cloud machine, first screen, sign-up, encrypted at rest
and who can read it; `<a id="cloud-hub"></a>` and `## A hub of your own in the cloud, for people with no computer`
before `<a id="security">`, with eight one-line decisions each ending "Not taken: …" and a table giving each of the six
agents a route word and an https terms link; one Decided row linking `#cloud-hub`; and
docs/evidence/1352/taste-call.json bound to the section's SHA-256.

Planted fix: all seven offline tests pass. AC4 (live) fails, as it should today: #1353 links only to #scale, #privacy,
#how-it-installs, and #1354 only to #security, #socket-roles-and-contract-versions, #states-people-see. With
`<a id="privacy">` and `<a id="security">` added above the planted heading, AC4 passes on the live bodies, which
exercises its pass path. The doc lanes test skipped there as `INCONCLUSIVE:` (packages/contracts/dist not built in the
clone), so its pass path was not exercised for this issue; it is 1336's test with only the section rule changed, and
1336's BASE-FAILURE.txt records its pass and mutant runs.

Mutants of the planted fix, each failing the test named, at the assertion named:

- the browser decision's words removed: AC1 section, "doesn't answer these decisions".

  since its new row names the hub and the cloud, as its rule allows).

- the new Decided row replaced with an unrelated one: AC1 Decided, "none of the Decided table's 1 new rows links".
- the Injected answers sentence kept, wrapped over two lines: AC2 old wording, "the old wording is still there".
- the threats row without "passkey": AC2 threats, "no row of the threats table holds all of".
- the privacy section left as at the base: AC2 privacy, "the privacy section is the same as at 6aa228ce".
