## The tests that pass on the base, and why

Each can only pass here. The wrong program named is run below.

- #1115.07ca71fc (all three): on the base the merge base's scripts and this checkout's are one program, so "before" and
  "after" can't differ. Wrong programs: unanchored-state, quiet-reporter, moved-a-failure. The real run on main is by hand.
- #1115.3a2181d7 a real failure beside a test failing with INCONCLUSIVE: every failure reads FAIL on the base. Wrong program:
  first-state-wins.
- #1115.82b1c824 a --record rewrite passes the guard: the base's guard doesn't read known-failures.json. Wrong programs:
  whole-file-rule, line-rule.
- #1115.82b1c824 subtest "the resolution keeps skips": the same reason, as the control beside "the resolution adds an entry",
  which fails on the base. Wrong program: whole-file-rule.
- #1115.1f2f1fa0 a unit lane with no grant: runLanes finds the throttle's line in the output on the base. Wrong program:
  empty-report-fails.

scratch folder. The suite passed 49 of 49 on it, on the same files as the run above. Each program below is that
implementation with one planted fault, run with the one test file that should catch it. Each failed the tests listed; I
read the assertion only for quiet-reporter, not for the rest. The throwaway copy isn't kept, so these runs show the tests aren't vacuous
and say nothing about the real change.
