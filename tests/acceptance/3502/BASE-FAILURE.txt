HOW IT WAS RUN, AND WHAT IS UNRUN

1. Through the throttle, as the lanes run a suite that is alone, no file ran. The first request,
     node scripts/throttle.mjs test --wait 60 -- node --test tests/acceptance/3502/pin.test.mjs
   waited its 60 minutes (18:25 to 19:25) and ended
     INCONCLUSIVE no grant: no test grant came within 60 min
   with exit 3. It was not asked again. So every file below is unrun under a grant.
2. The tests that start no cargo and no workspace binary were then run once each, directly, as
     CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 node --test tests/acceptance/3502/<file>
   Those are the results marked "direct" below. No run started cargo.
3. The tests that drive the base's built deep-show and deep-drive were not run as test files. Their statements were
   run as probes on those binaries, through the suite's own helpers, with DEEP_BIN_DIR naming the checkout's
   target/debug so that nothing was built. Those are the results marked "probe" below. A probe is a reading of the
   base, not a test run.
4. Never run, here or anywhere: build.test.mjs's cargo build, rows.test.mjs's run of every row's test, and the two
   tests that judge a time on a release build (each stops before it builds, as below).
