  packages/supervisor/src/index.ts (openSupervisor, seatbelt, sandboxSuite, plantedBackends, ...) doesn't
  exist. That covers AC1, AC3, AC4 (library half), AC5, AC6, AC7 (decoy), AC8, AC9, AC10, AC11, AC12 and
  AC13 (host@1 contract).
- hub.test.ts AC2: the hub's run.start doesn't sandbox, so the probe the run starts connects to the hub's
  own socket.
- hub.test.ts AC7: the hub doesn't record process.tracked for a run's processes, so a restart that has only
  the record has nothing to reap from (timed out waiting for process.tracked).
- hub.test.ts AC13: the hub doesn't start check runs through a host@1 module (DEEP_HUB_TEST_HOST is ignored),
  so the recording host's log has no start. The planted program DEEP_HUB_PLANT=run-spawns-itself doesn't
  exist, so the hub refuses to start and the test reports BLOCKED rather than the expected failure.
- blocked.test.ts: BLOCKED by design. The surfaces these halves need aren't built at this base: the runner
  (#159) for AC4's read-only job, the command check kind (#30), environments (#36/#331) and the check-kind
  extension slots (#349) for AC13. A blind redraft writes them once those exist.
