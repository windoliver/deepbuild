Before it passed, the throwaway failed these tests for its own faults, each caught where it should be: a 2 s control
timeout under load (the first promotion's health check, "the fixture claim couldn't be judged: no answer within
2000 ms"); a drain read from the session's live state, which a prompt with no transcript entry never sets ("the
build … started as the installed hub 1.4 s after the promotion was asked for, while the session's turn ran"); one
start of the service while the old hub's process was still ending, a no-op for launchd ("the planted crash build …
never ran"); and a drain that waited on a Stop the hub only took late, from the spool, so it never ended.
