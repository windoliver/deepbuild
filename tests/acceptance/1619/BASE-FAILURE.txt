#1619 acceptance suite at the base, 16dc5eab (Merge pull request #2771), before any implementation.

One run of the suite as delivered, on an Apple M5 Max (Metal, GPU family apple10), with
`node scripts/throttle.mjs build --wait 60 -- npx vitest run --root tests/acceptance/1619 --no-file-parallelism
--testTimeout=600000 --no-color` (deep-gpu built by each file, debug, CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0;
it had been built once before the run, so the files' builds found it fresh). It is the suite's second run at the
base: after the first, seek.test.ts's three seeks were moved into a second process, and the ten results were the
same. 8 of 10 tests fail, each on the surface the base lacks:

- line.test.ts: at `convergence_angle: 90` the base's pass ignores the angle, so red and blue stay in green's row and
  slide 2 px along it; `--planted convergence_angle_ignored` is refused at startup (`bad_input`, exit 2).
- seek.test.ts: on the noop backend no frame has a `finish_hash`; on Metal the tracking band and the roll draw
  nothing, so every played frame is the frame with no finish (the seeked frames do equal the played ones there, which
  is why the test also asks that the band shows); `--planted tracking_wall_time` is refused at startup on both
  backends.
- identity.test.ts: the identity's equalities hold at the base, which ignores `tracking` and `roll`, and
  `convergence: 2` changes the film; the test fails on its guard, since a tracking band and a roll change no frame.
- indexed.test.ts: the base draws the indexed look whose screen names `convergence_angle` instead of refusing it.

The 2 that pass are line.test.ts's two tests at `convergence_angle: 0`: the peaks of the vertical line, and its
frame against the merge base's frame (fixtures/base-frame.png, drawn by this same build on this same GPU). The
criterion's first half holds the new pass to what #464's horizontal convergence already draws, so both pass before
and after; they fail on a pass whose angle 0, or whose default angle, moves a pixel of the base's frame (README: What
the base already does).

`npx tsc -p tests/acceptance/1619/tsconfig.json` exits 0. No test was INCONCLUSIVE here: the machine is a Mac of the
family that drew the merge base's frame. The suite was not run on the Spark or on a Mac of another GPU family.
