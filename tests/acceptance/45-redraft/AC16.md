# #45 AC16 (`#45.5f772137`)

**Criterion:** A check held through three goal turns, each newer snapshot taking its held place, and started at the goal's end reads three held places taken, the runs the loop saved, and one start, by the loop's pause, with its wait from its own stop; a reading that counts the held places as runs fails this test.

**Surface:** `loopHolds(events)` from `packages/readings/src/index.ts` (readings-surface.md), fed one Codex goal session's record in the base's published shapes: `user.ask@2` (`from: continuation`), `agent.stop@5`, `stop.held@1`, `check.held@1`. Test: `lifecycle.test.ts`.

**Session:** five goal turns, 60 s of work each, 2 s fast lanes, each continuation 1 s after the reply. The first four stops hold the journey; snapshots 2, 3 and 4 each take the place before. In the fifth turn the goal ends, and the fourth snapshot's held place starts when that stop's fast lane ends. Expected: places_taken 3, runs_saved 3, runs_started 1, one start by `loop_paused`, waited 65 s (from stop 4's request) or 63 s (from its reply).

**Open choices:**
1. A held place is a `check.held@1` record, re-appended whole on each change, the newest per check and snapshot standing: taken = `replaced_by` set, started = `started_by` set (8 events, 4 places).
2. Runs saved = held places a newer snapshot took before they started (design wording), so 3.
3. The place that starts at the goal's end is the fourth snapshot's (the base gate runner records the start on the held record; the fifth snapshot is never held). "Its own stop" is therefore stop 4, not stop 1 (254 s) or stop 5 (0–2 s).
4. A stop's time is either its request stamp (ULID/`agent.stop` ts) or its reply (`held_at`); both edges of stop 4 are accepted.
5. "The loop's pause" is `loop_paused`, the value `check.held@1` publishes.
6. Core events (`stop.held`, `check.held`) carry `session: null`, as the base's gate runner appends them; their session is `data.session`.

**Wrong program:** a reading that counts each held place as a run (runs_started 4, runs_saved 0, four starts) is built in the second test and must fail the same assertions.
