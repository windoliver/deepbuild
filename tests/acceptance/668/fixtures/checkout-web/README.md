# checkout-web

The checkout page of a small web shop: a cart, a total and a pay button.

## Run it

Open `index.html` in a browser. There is no build step.

## Test it

Run `node --test`. The tests are in `test/`.

## Layout

- `index.html`: the page.
- `src/cart.js`: adds up the cart.
- `test/checkout.js`: the checkout test.
