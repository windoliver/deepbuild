  nothing, and the base IS the spike window, so the judge names it. That is the criterion's failure, seen on the real binary.

  Sessions; no rows; the menu bar reads ["143"].
- AC1 proof: `deep-replica --first-screen` over this home's hub draws no session row at the base: its reader folds no history
  from before it opened. The same reader feeds the app, so what fills the real sidebar should fill the replica's.
- AC2: stops at its precondition: before the answer the window reads 143, not 3 (the same 12 failures).
- AC3: "Needs you has no row showing <ask>'s question", naming each ask. AC3's plant: at the base the plant changes nothing,
  so the row isn't there at all and the test wants "by its handle" (a seam that doesn't exist yet). With a temporary build
  whose main.rs opened views::Shell, reverted, this same test passed on real handle rows (README).
- AC4 panel: "the plug-in panel draws no stale value 182.40", read off the pixels of the window `--panel` opens at the base.
- AC4 terminal: "the terminal tab can't be reached: the sidebar has no row "Cart totals" to click". The grid's pixel judge can't
  run at the base (no tab, a seam that doesn't exist yet); judges.test.ts shows it on drawn pictures. The plant fails likewise.
- AC5: stops before the press: the main window doesn't draw Needs you at all. The Pop out control doesn't exist yet.
- AC6: "the welcome pane's ground in dark mode is #f6f6f4, not the look's dark ground #0b0c0e", and light "#f6f6f4, not
  #ffffff": the pane's Paper, on the real window's pixels. DEEP_APP_APPEARANCE is unread at the base, so dark draws light.
- AC7: every picture written (15 files, the window ones at 3024 x 1964), then "INCONCLUSIVE: AC7: no taste call is recorded".

What could not run at the base: nothing failed to run, but the judges for the card, the stale value's ink, the cell grid's law on
