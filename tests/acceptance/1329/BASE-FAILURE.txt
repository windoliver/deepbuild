(scripts/design-names.mjs: backticked `deep …` and `deep_…` names in each open issue must appear in backticks in the
docs or in scripts/planned-names.txt, and each blob link into docs/*.md must land on a slugged heading), a

scripts/studied-names.json), both added to `checks` after `design links`, and CONTRIBUTING.md's line rewritten to
name the two docs as the source. All seven offline tests passed (each 2 to 4 minutes on a Mac at load average ~600,
where the throttle holds lanes). The plant was then removed and scripts/lanes.mjs and CONTRIBUTING.md restored from
git before the base run above; none of it is part of this suite.
