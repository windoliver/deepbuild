No implementation existed when these tests were drafted, so no twin folder is here yet. Each twin is the merged work
with exactly one fault, as below, and nothing else changed. A twin changes product files only, never a file under
`tests/`, and is kept as its wrong lines in `twins/<name>/lines.json` (the line form, `tests/acceptance/1832/README.md`),
never as a whole copy of a file. "Replaces" names the files its lines change as the base has them; the implementer
names the real ones. The tests run unchanged on a twin and select none: the two planted folds and the start's wait
(`../README.md`, Defined here) are settings of a correct program, set the same on the work and on every twin.
