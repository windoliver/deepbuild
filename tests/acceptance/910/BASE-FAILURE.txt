DEEP_OPEN_ISSUES, else a target/open-issues.json written in the last 10 minutes, else gh issue list --state open
--limit 5000 --json number,body (writing the cache). Offline with neither, it prints INCONCLUSIVE and exits 1. It
slugs headings by GitHub's rules (README: Slugs), counts <a id>/<a name>, skips fenced code, prints
'FAIL <n> of <count> links ...' then one line per bad link ('docs/x.md:<line> links <raw> (...)' or
'#<n> links docs/x.md#<anchor> (...)'), else 'design links: <count> links from 2 docs and <n> open issues land on a heading'.
