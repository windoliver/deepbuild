2. No vitest run. Two were queued through the build slot, as every file builds:
     node scripts/throttle.mjs build --wait 180 -- sh scripts/lease node node_modules/vitest/vitest.mjs run \
       --root tests/acceptance/161 --no-file-parallelism --testTimeout=600000 ac8-invert-premultiplied.test.ts
     (the same) ac3-pack-check.test.ts ac9-alpha-guard.test.ts ac10-moved-group.test.ts ac12-linear-color-key.test.ts
   Neither was granted the slot within this job's time (five other sessions' builds were queued ahead of them), so
   both were stopped, by PID, having run nothing. No test below has an observed vitest result at the base.

3. Instead, the base's two binaries were driven directly with this suite's own documents and calls (helpers.ts,
   fixtures.ts, title.ts, measures.ts, from scratch scripts that are not delivered), to see that each is well formed
   wherever the base takes it and what the base answers. Every line under "at the base" below is one of those
   answers; each test's failing assertion is read from them and from the test's code, not from a run of the test.
