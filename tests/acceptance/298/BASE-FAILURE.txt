What the base has and lacks, read from its code:

- `overlay.frame@1` anchored to an item's point draws with its frame's top left corner at the point's projection plus
  its offset, wherever that falls, and has no place while the point is behind a perspective camera
  (crates/deep-canvas-scene3d/src/scene.rs, `overlay`; `Camera::project` returns none at a depth of 0 or less).
- `hide` is read only where the overlay has a `leader`, and takes `off_frame` or `never`; any other value there is
  refused, `out_of_range` at `items/<id>/params/hide` (the same function). Without a leader, `hide` and `clamp_inset`
  aren't read: scene3d's spec holds no param list for `overlay.frame@1`. If a document check ahead of it refuses the
  unknown value or field instead, each view3d test below fails one step earlier, at "… was drawn, not refused".
- `view3d`'s `overlays: true` rows are `{id, at}` and, with a leader, `leader: {to} | null`
  (crates/deep-gpu-layer/src/view3d.rs). No `edge`, no `edge_angle`.
- A driver var written `<name>.<field>` is a logic array's; one that names no baked array is refused,
  `ref_unresolved` at `drivers/<id>/vars/<name>` (crates/deep-canvas-motion/src/doc.rs, `driver_of`;
  program/groups.rs). So no driver reads `tag-east.edge_angle`.
- Every name a driver's `expr` reads must be one of its vars, else `ref_unresolved` at `drivers/<id>/expr`
  (`driver_of`); the closed function list has no `hover_at` (crates/deep-canvas/src/expr.rs). So the card's drivers are
  refused.
- A logic item's read that names no control, reading or logic array is refused, "names no control or logic item of
  this piece" (crates/deep-logic/src/piece/checks.rs, `region_map`): a read of a driver, of a path or of
  `hover_at(card)` is refused at the base already, for that reason.
- `deep-gpu run --planted <name>` with a name `Planted::parse` doesn't know prints {"ok": false, "code": "bad_input"}
  and exits 2 (crates/deep-gpu-layer/src/main.rs); `deep-show run` answers a scenario whose `planted` it doesn't know
  {"ok": false, "code": "bad_input"} (crates/deep-show/src/main.rs).
