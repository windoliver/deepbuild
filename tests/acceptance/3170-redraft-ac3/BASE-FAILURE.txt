paths): with the runner naming /srv/deep-cow, which this machine lacks and whose parent is root's, the cli test panics

test on the Spark: cargo refused to merge that table with the string the Spark's ~/.cargo/config.toml gives the same key
("expected table, but found string"), and the test threw at its setup check, which is no proof. The twin is a Linux
target runner instead, which no user config here sets.
